Mijn blog

Mijn eerste stappen met HTML

Voor Opdracht 1 werk ik aan mijn persoonlijke portfolio. Met deze website wil ik laten zien dat ik HBO-ICT studeer in de richting Software Engineering en aan welke projecten ik werk. Ik maak de website voor toekomstige studenten en recruiters.

De structuur van mijn website

Mijn website heeft drie pagina's: Home, Projecten en Blog. Op Home stel ik mezelf voor en vertel ik wat ik leer. Op de projectpagina beschrijf ik Panda Restaurant Simulator en mijn eigen bijdrage. Op deze blog vertel ik over het maken van mijn website.

Ik gebruik de header voor de bovenkant van de pagina en de nav voor de links naar de drie pagina's. In main staat de belangrijkste inhoud van elke pagina. In de footer staat onderaan mijn portfolionaam.

Een probleem met mijn navigatie

Toen ik mijn projectpagina wilde openen, kreeg ik de melding “Cannot GET /projecten.html”. Daardoor kon ik de pagina op dat moment niet bekijken.

Mijn aanpak

Ik ben verdergegaan met mijn website en heb de projectpagina later opnieuw geopend. Toen kon ik projecten.html wel bekijken.

Wat ik heb geleerd

Met een link zoals <a href="projecten.html">Projecten</a> verwijs ik naar een HTML-bestand in dezelfde map. Als een pagina niet opent, wil ik de volgende keer eerst controleren of het bestand bestaat en of de bestandsnaam in de link precies klopt.

Mijn volgende stap

Ik wil de teksten van mijn portfolio verder controleren en aanvullen. Vooral op de projectpagina wil ik duidelijk maken wat Panda Restaurant Simulator is en wat ik zelf aan het project bijdraag. Zo kan een recruiter mijn werk beter begrijpen.
